# AraPal Design Notes

## Accent Blue Tokens

AraPal uses a single accent-blue family across the product. This should stay consistent between `Home`, `Source + Segmentation`, and `Study`.

- `Accent Blue / Base`: `#2563EB`
  Use for default active controls, primary CTA fills, active icons, and selected-state emphasis.

- `Accent Blue / Soft`: `#93C5FD`
  Use for hover-adjacent highlighting, selected-but-secondary surfaces, focus halos, soft borders, and light accent washes.

- `Accent Blue / Strong`: `#1D4ED8`
  Use as the darker companion to the base blue for hover, pressed states, and gradient endpoints on solid primary controls.

Practical rule:
- resting primary / selected = `Accent Blue / Base`
- hover / pressed = `Accent Blue / Strong`
- hover wash / selected background / focus treatment = `Accent Blue / Soft`

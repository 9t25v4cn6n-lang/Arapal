# Arapal

Arapal is a serious Arabic/language-study product currently being converged to V1 release.

## Canonical project documents

- `AGENTS.md` — permanent operating doctrine.
- `PROJECT.md` — stable product model, V1 scope and user journeys.
- `DECISIONS.md` — current durable decisions.
- `docs/release/00-RUNBOOK.md` — exact release workflow.
- `docs/release/ARAPAL_RELEASE_CONTRACT.md` — definition of finished/releasable.
- `docs/release/ARAPAL_RELEASE_LEDGER.md` — current work, blockers and evidence.
- `docs/release/ARAPAL_VISUAL_PRODUCT_STANDARD.md` — professional visual/product judgement.
- `docs/reference/FIGMA_REFERENCES.md` — current design-reference navigation.

Use `package.json` for current executable commands. Do not rely on archived prose for command names or current status.

Historical audits and Figma reconstruction files are retained under `docs/archive/` only for provenance.

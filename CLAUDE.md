# Arapal — Claude Entry Point

Arapal's canonical instructions are in `AGENTS.md`.

Before work, read in this order:

1. `AGENTS.md`
2. `PROJECT.md`
3. `DECISIONS.md`
4. `docs/release/ARAPAL_RELEASE_CONTRACT.md`
5. `docs/release/ARAPAL_RELEASE_LEDGER.md`
6. `docs/release/PROMPTS.md` section named by `docs/release/00-RUNBOOK.md`

Do not use files under `docs/archive/` as current instructions or current status.

Two distinctions matter:

- **Mechanical visual floor**: use the repository's executable QA/checker (`scripts/qa/standard.mjs` and current package scripts).
- **Professional visual/product judgement**: use `docs/release/ARAPAL_VISUAL_PRODUCT_STANDARD.md` and inspect rendered evidence.

Do not treat Figma pixels, historical violation counts, old checklists or stale TODO entries as the release objective.

The objective is the release outcome defined in `docs/release/ARAPAL_RELEASE_CONTRACT.md`.
